# Fixed positive sampling is nearly saturated

Paper and reproduction materials for Kellen Heraty's Phase 1 submission to the
ARC White-Box Estimation Challenge 2026.

- AIcrowd username: `kaileh57`
- Submission: [`327786`](https://www.aicrowd.com/challenges/arc-white-box-estimation-challenge-2026/submissions/327786)
- Materials: [latest GitHub release](https://github.com/kaileh57/whitebox-phase1-327786/releases/latest)

The release contains the paper and a frozen artifact archive. The archive
includes the estimator source, retained upload, proof certificates, empirical
receipts, manifest, and reproduction instructions. The paper studies the
estimator's unpruned Kerdock sampling core; adaptive pruning and the leaderboard
result are reported separately.
